**关键接口：**

| 方法 | 路径 | 参数 | 用途 |
|------|------|------|------|
| GET | `/api/v1/projects/{id}` | — | 项目详情（可选，失败可回退列表缓存） |
| GET | `/api/v1/projects/{id}/files` | — | 映射文件列表 |
| GET | `/api/v1/projects/{id}/file-detail` | `?file=` 路径 | 单文件修改历史（`records`） |
| GET | `/api/v1/projects/{id}/change-docs` | `?date=` 日期 | 修改文档正文详情 |

**字段映射（摘要）：**

| 接口字段 | 前端 |
|----------|------|
| `file` / `module` / `changeCount` / `lastDate` | 文件列表行 |
| `records[].reason` / `requirementDesc` / `date` / `author` | 简略历史 / ChangeDoc |
| `rawContent` / `items[]` / `requirementDesc` 等 | 修改文档正文页 |

**注意事项：**
- 浏览器对 **GET + body** 支持差，`file` / `date` 一律走 **query**，避免「路径/日期不能为空」
- 文件主键用路径；路由 `fileId` 需 `encodeURIComponent`
- 进入概览后：加载文件列表 → 选中第一项 → 立刻调一次 `file-detail`
