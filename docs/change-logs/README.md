# 前端更改记录

本目录用于存放 **DocumentSummarization（doc-sum）前端代码** 变更记录。

## 规则

| 项 | 说明 |
|----|------|
| 何时写 | **仅当实际修改了前端代码**时写入；纯文档/核查/规则调整不写 |
| 命名 | `YYYY-MM-DD-{git config user.name}.md`（例：`2026-09-02-baiyu21.md`） |
| 模板 | 同目录 `YYYY-MM-DD-变更人名称.md` |
| 顺序 | 先删除代码记录，再新增代码记录 |
| 粒度 | 用户一次含代码修改的需求 = 一份记录（同日追加小节） |

格式对齐团队约定（参考 rd-xmz `docs/前端更改记录`）。
