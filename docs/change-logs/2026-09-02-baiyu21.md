## 变更说明

### 变更原因
原工程仅有 layouts / router / views，缺少请求封装、目录分层、环境隔离、CI、提交钩子；登录未写入会话，无法支撑后续鉴权与联调。

### 影响范围

### 注意事项
- 业务页仍可走 mock；真实 API 通过 `request` 接入
- husky hooks 挂在 monorepo 根；本机需 PATH 含 git
