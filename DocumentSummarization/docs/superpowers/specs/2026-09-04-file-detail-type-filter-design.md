# 文档详情 · 变更类型筛选

> **日期**：2026-09-04  
> **范围**：`ProjectFileDetail.vue` 左侧修改历史  
> **状态**：已确认（方案 A · 单选下拉）

## 需求

在文档详情页用单选筛选框按变更类型过滤历史：全部 / 新增 / 修改 / 删除。

## 设计

1. 筛选放在「修改历史与对应文档」标题行右侧。
2. 选项：`all`（默认）/ `add` / `modify` / `delete`。
3. 仅过滤左侧列表；按 `typeCode`（兼容中文类型文案）。
4. 当前选中被滤掉时，改选筛选结果第一条；无结果则清空右侧。
5. `ChangeDoc` 增加 `typeCode`；normalize 时与展示用 `type` 分开。
6. 不做：多选、URL 同步、改顶部统计。
