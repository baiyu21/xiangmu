# 文件映射页布局调整 · 左列表 + 右简略历史

> **日期**：2026-09-03  
> **范围**：`ProjectOverview.vue` + `ProjectFileDetail.vue`（query 预选）  
> **状态**：已实现（方案 A，用户确认后直出）

## 目标

1. 去掉模块/仓库「板块层级」树与模式切换  
2. 左侧：原文件列表（点选，不整行跳转）  
3. 右侧：当前文件修改历史**简略版**（时间 / 作者 / 标题 / 摘要）  
4. 点击某次修改 → 进入文档详情（完整 AI 简介 + 客户注释等），并预选该记录

## 交互

| 操作 | 结果 |
|------|------|
| 点击左侧文件行 | 右侧刷新该文件简略历史 |
| 点击「详情」按钮 | 进入文档详情（默认最近一次修改） |
| 点击右侧历史条目 | 进入文档详情，`?doc={docId}` 预选中 |

- `FileMapTree`、模块/仓库模式切换、scope 范围筛选 UI  
- `FileMapTree.vue` 组件文件保留，供后续复用
